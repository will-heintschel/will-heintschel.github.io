# will-heintschel.github.io

Personal portfolio site; cybersecurity projects, game dev, and background.

Live at: https://will-heintschel.github.io

## Structure
- `index.html`, `about.html`, `projects.html`, `games.html`, `contact.html` - pages
- `404.html` - custom not-found page
- `resume.pdf` - downloadable resume
- `robots.txt`, `sitemap.xml` - crawler/indexing config
- `src/style.css`, `src/script.js` - shared styles/scripts
- `src/images` - images and favicons

## Features
- Interactive terminal on the homepage (`help`, `whoami`, `ls`, `cat resume.txt`, `open <page>`, `clear`)
- Rotating wireframe globe on the about page, with real (simplified) coastlines and a pulsing Houston, TX marker

## Stack
Plain HTML/CSS/JS, no build step. Hosted on GitHub Pages.
