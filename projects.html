project 01

Personal Homelab & Self-Hosted Infrastructure

An ongoing Ubuntu Server build run like it matters — segmented access, active monitoring, and documentation for every change. The goal was never just "get it running," it was to practice the habits a security operations role actually requires.

$ docker compose ps
12 services — jellyfin, sonarr, radarr, prowlarr,
bazarr, qbittorrent, portainer, uptime-kuma,
watchtower, homepage, glances, pi-hole
$ all healthy

access & perimeter

FIREWALL

UFW rules scoped to trusted ranges. SSH and other sensitive ports are restricted to the local network and Tailscale VPN range only — nothing sensitive is reachable from the open internet, which cuts the exposed attack surface down to what actually needs to be public (Pi-hole's DNS port, network-wide).

VPN

Tailscale for remote access. Every device reaches the homelab over an encrypted mesh VPN — no port forwarding, no public-facing admin panels. Access is device-authenticated rather than perimeter-based, following zero-trust principles at homelab scale.

DNS

Pi-hole + DNS-over-HTTPS. Network-wide DNS filtering blocks known ad/malicious domains before they resolve, with DoH encrypting the resolution path itself so DNS traffic can't be trivially inspected or spoofed on the local network.

monitoring & response

UPTIME

Uptime Kuma tracks every service. HTTP health checks run continuously; a service going down triggers an alert instead of being discovered the next time someone tries to use it.

ALERTS

Real-time Telegram notifications. Wired into Glances for CPU/RAM/temperature thresholds and into Radarr/Sonarr for download and health events — the same "alert fires, get triaged" loop as a SOC dashboard, just running against a homelab instead of an enterprise SIEM.

LOGS

Ongoing log analysis. Service and container logs get reviewed to catch misconfigurations and connectivity issues before they become outages, not just after something breaks.

orchestration & upkeep

CONTAINERS

Portainer + Watchtower. Portainer gives a single pane of glass over the container stack; Watchtower keeps images patched automatically, closing the gap between a CVE landing and the fix actually shipping.

NETWORK

Static IP & DNS via Netplan. Predictable addressing across the network, documented alongside the rest of the architecture so the whole setup is reproducible, not just remembered.

DASHBOARD

Homepage as the control surface. A unified dashboard pulling live widgets from every service via API keys — one place to see the health of the entire stack at a glance.
